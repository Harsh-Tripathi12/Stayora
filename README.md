# AirBnb - Like hosting website 
Owners can log in and list their properties. Only the property owner is authorized to edit or delete their own listings.

Users can post reviews and rate listed properties using a star rating system.

Authentication is implemented for both owners and users, ensuring that only authorized users can access and perform their respective actions.

It uses an API to display the property's location on a map, making it convenient for users to find and navigate to the destination.

There is still a lot of work pending, but you can take a look at what I've built so far.

Live demo: https://majorproject-1km4.onrender.com/listings
