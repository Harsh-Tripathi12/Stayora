# Stayora – Property Rental & Hosting Platform

Stayora is a full-stack property rental platform inspired by Airbnb. It allows property owners to list and manage their properties while helping users discover, review, and explore available stays.

The project focuses on secure authentication, property management, user reviews, and interactive maps.

## Features

### Property Management
- Property owners can register, log in, and list their properties.
- Owners can edit or delete only their own listings.
- Users can explore available properties and view their details.

### Authentication & Authorization
- Authentication is implemented for both property owners and users.
- Authorization ensures that users can perform only the actions permitted for their accounts.
- Property ownership is verified before allowing listing modifications.

### Reviews & Ratings
- Users can post reviews for listed properties.
- A star-rating system allows users to share their experience and help others evaluate properties.

### Interactive Maps
- An external API is used to display property locations on an interactive map.
- Users can explore the location of a property and better understand its surroundings.

### Admin Panel
- An admin panel has been added to the project.
- The project is being developed further, with additional functionality planned.
